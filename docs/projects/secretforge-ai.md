# secretforge-ai

## Registry role
AI-powered secret-management platform for detecting required API keys and managing project secrets.

## Orion relationship
Security dependency for identifying and supplying runtime configuration without committing secrets to Orion.

## Integration boundary
Orion should consume references or injected values only; secret material must remain outside the repository and logs.
