# Effort Governor

## Registry role
Governance system for controlling effort, scope, prioritization, and execution budgets.

## Orion relationship
Use as a policy layer around Orion work: decide what to attempt, how much effort to spend, and when to stop or escalate.

## Integration boundary
Inputs should include task priority, constraints, budget, and observed progress. Outputs should be auditable decisions.
